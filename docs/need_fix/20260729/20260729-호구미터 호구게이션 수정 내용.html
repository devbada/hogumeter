20260729-호구미터 호구게이션 수정 내용



  • 자동차 아이콘 위치를 아래 (예상 거리 | 예상 시간 | 예상 호구비) 정보창으로 가깝게 위치 이동하며 지도의 기준점이 아래로 보이도록 조정 (윗부분 정보는 더 많이)


  • 이동 중 정보 안내 표시구간의 실시간 변경필요함. 5.3km 라고 표시된 부분이 고정되어 있음. 그러나 경로를 재탐색하는 경우 다시 설정됨.


  • 자동차의 위치가 “경로안내 표시라인"의 위로 이동시켜주길 바람. 현재 gps 의 위치기반으로 보여지는것이 맞음. 그러나 도로가 넓은 경우(예 편도 6차로) 도로의 크기가 작게 표현되고 있어서 그렇게 보이는 듯.



  • 예상 거리 | 예상 시간 | 예상 호구비  = 실시간 변경이 필요함. 단 예상 호구비 = 처음 출발할 때의 금액도 일치하거나 비슷해야 함 (조정이 되더라도) 
  • 왜냐하면 재설정으로 인하면 이동했던 거리만큼의 비용이 사라지기 때문.


  • 네비게이션의 다음 경로라인은 “우회전"이 맞지만 “정보창"에는 “920m 후 좌회전”을 하라고 표시되고 있음.
  • 원하는 것은 다음 경로의 회전 반경 정보가 필요함. 그리고 그 정보의 거리 정보도 실시간으로 변경되어야 함.


  • 호구게이션 위치 설정 후 동작 시 “가장 하단” 네비게이터 영역은 hide 처리가 어떤지 제안함. hide 에서 다시 show 할 때는 별도의 작은 아이콘 (예; 🔝 같은 것이 있으면 좋겠음)


  • 호구게이션 위치 설정 후 동작 시 “가장 상단” 호구게이션 타이틀 영역을 숨기고 더 넓게 처리하면 좋겠음
