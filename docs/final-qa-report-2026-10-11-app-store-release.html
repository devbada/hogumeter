PC에서 할 일

  1. App Store Connect에서 upload된 build 1.5.3 (1)이 처리 완료된 뒤 1.5.3 버전에 연결한다. 이미 같은 build 번호가 존재하면 빌드 번호를 2 이상으로 올려 새 archive를 만들어야 한다.
  2. 제출 내용 초안의 ‘새로운 기능’과 ‘앱 심사 메모’를 입력한다.
  3. App Privacy, 연령 등급, 가격/배포 국가, 수출 규정, 심사용 연락처·데모 정보, 개인정보처리방침 URL을 확인·입력한다.
  4. 6.5인치 비투명 PNG 세트(appstore/marketing-6.5-1284x2778)와 iPad 스크린샷이 현재 1.5.3 UI를 정확히 반영하는지 확인 후 업로드한다. 제거된 호구게이션을 암시하는 지도 캡처는 사용하지 않는다.
  5. TestFlight에서 백그라운드 GPS 연속성, 자동 잠금, 장시간 발열을 실기기로 다시 확인한 뒤 심사 제출한다.

알려진 제한

  • 이 보고서는 upload 및 심사 제출을 수행하지 않는다.
  • App Store Connect의 동일 build 번호 여부와 메타데이터 완결성은 계정 화면에서 확인해야 한다.
  • 앱은 UserDefaults 및 FileManager를 사용한다. 업로드 시 Apple의 Privacy Manifest/required-reason 경고가 발생하면 해당 경고에 맞추어 PrivacyInfo.xcprivacy를 추가·검증한다.
