실시간 요금 계산

GPS로 이동 거리와 시간을 재고, 택시미터기처럼 호구비를 실시간으로 계산해요.

  • 거리 요금과 시간 요금 반영
  • 현재 속도와 주행 시간 표시
  • 일시정지 없이 드라이브 흐름에 맞춰 사용
🏙️

지역별 요금 설정

서울, 부산, 대구, 인천, 광주, 대전, 경기 기준 요금을 제공하고 직접 조정할 수 있어요.

  • 기본요금, 거리요금, 시간요금 설정
  • 지역별 요금 저장
  • 심야 시간대 요금 기준 반영
🗺️

이동 경로 기록

주행이 끝난 뒤 이동 경로를 지도에서 다시 볼 수 있어요.

  • 실제 이동 경로 지도 표시
  • 주행 거리, 시간, 요금 함께 확인
  • 기록 화면에서 지난 드라이브 다시 보기
🧭

호구게이션

목적지를 검색하면 예상 거리, 예상 시간, 예상 호구비를 먼저 보여주는 장난용 내비 모드예요.

  • 출발지와 목적지 검색
  • 경로 미리보기와 예상 호구비 계산
  • 내비 시작 시 미터기도 함께 시작
  • 현재 호구비와 예상 호구비 동시 표시
  • 경로 이탈 시 현재 위치 기준으로 다시 경로 계산
🧾

영수증 생성

주행 결과를 영수증처럼 만들어 친구에게 공유할 수 있어요.

  • 총 요금, 거리, 시간 요약
  • 요금 상세 내역 표시
  • 이미지로 저장하고 공유
🌙

심야 할증 자동 적용

밤 시간대에는 설정된 심야 요금 기준을 자동으로 반영해요.

  • 시간대별 요금 구분
  • 지역 요금 설정과 함께 적용
  • 실제 요금이 아닌 재미용 계산
🚕

지역 할증 모드

리얼하게 즐기고 싶다면 시계외 할증 느낌의 지역 할증 모드도 켤 수 있어요.

  • 지역 할증 사용 여부 선택
  • 실제형/장난형 모드 선택
  • 친구들과 정한 놀이 규칙에 맞게 조정
📷

과속카메라 참고 표시

호구게이션 중 경로 근처 카메라 정보를 참고용으로 보여줘요.

  • 진행 방향 기준 가까운 카메라 표시
  • 제한속도 원형 표지 표시
  • 3km/h 이상 초과 시 작은 초과 표시
📊

기록과 통계

드라이브 기록을 쌓아두고 얼마나 달렸는지 통계로 확인할 수 있어요.

  • 최근 주행 기록 보관
  • 누적 거리와 요금 요약
  • 월간/주간 흐름 확인
🔒

기기 안에서 관리

주행 기록과 설정은 기기 안에서 관리하고, 광고 없이 가볍게 사용할 수 있어요.

  • 서버 전송 없는 로컬 저장 중심
  • 광고 없는 사용 경험
  • 설정에서 데이터 관리

차에 타서 호구미터를 켜세요

4

도착하면 기록과 영수증으로 친구에게 장난쳐보세요 😂

📢 알아두세요

  • 이 앱은 친구들과 재미로 즐기는 용도입니다
  • 실제 택시 미터기는 바퀴 회전수로 계산하고, 이 앱은 GPS를 사용합니다
  • 그래서 실제 택시 요금과 차이가 있을 수 있어요
  • 터널이나 지하에서는 GPS 오차가 발생할 수 있습니다
  • 호구게이션과 과속카메라 표시는 참고용이며, 실제 운전 판단은 도로 상황과 교통 법규를 우선하세요
  • 진짜 요금 확인은 택시 미터기를 보세요! 😊

⚠️ 면책 조항

"호구미터"는 오락 및 재미 목적으로만 제작되었습니다.
친구들과 드라이브하며 장난으로 즐기는 앱입니다.

❌ 실제 택시 요금을 확인하는 용도가 아닙니다
❌ 바가지 요금을 검증하는 용도가 아닙니다
❌ 요금 분쟁 시 근거 자료로 사용할 수 없습니다

GPS 기반 측정은 실제 택시 미터기(바퀴 회전 기반)와 다르며,
측정 환경에 따라 오차가 발생할 수 있습니다.
