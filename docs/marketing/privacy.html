호구미터 (HoguMeter)

개인정보 처리방침

최종 수정일: 2026년 6월 24일

1. 개요

호구미터(이하 "앱")는 친구들과 함께하는 드라이브를 더 재미있게 만들어주는 엔터테인먼트 목적의 택시미터기 시뮬레이션 및 목적지 기반 호구비 예측 앱입니다.

본 개인정보 처리방침은 앱이 어떤 정보를 수집하고, 어떻게 사용하며, 어떻게 보호하는지 설명합니다.

2. 수집하는 정보

2.1 위치 정보

항목내용
수집 목적이동 거리 측정, 요금 계산, 호구게이션 경로 표시 및 현재 위치 표시
수집 항목GPS 좌표 (위도, 경도), 이동 속도, 이동 방향, 위치 정확도
수집 시점미터기 또는 호구게이션 작동 중
저장 위치사용자 기기 내 (로컬 저장)
외부 전송경로 계산, 장소 검색, 역지오코딩을 위해 Apple MapKit 서비스에 필요한 정보가 전송될 수 있음
중요: 주행 기록과 설정은 사용자 기기 내에 저장됩니다. 다만 호구게이션의 장소 검색, 경로 계산, 주소 변환 기능을 제공하기 위해 Apple MapKit 서비스와 통신할 수 있습니다. 호구미터 개발자는 별도 서버에 사용자의 주행 기록을 저장하지 않습니다.

3. 수집하지 않는 정보

호구미터는 다음 정보를 수집하지 않습니다:

  • 이름, 이메일, 전화번호 등 개인 식별 정보
  • 계정 정보 (회원가입 기능 없음)
  • 결제 정보
  • 연락처, 사진, 캘린더 등 다른 앱 데이터
  • 광고 식별자 (IDFA)
  • 기기 고유 식별자
  • 사용 행태 분석 데이터
  • 개발자 서버에 저장되는 위치 기록

4. 정보의 사용 목적

수집된 정보는 오직 다음 목적으로만 사용됩니다:

목적설명
요금 계산GPS 기반 이동 거리 및 시간 측정으로 가상의 택시 요금 계산
호구게이션목적지 검색, 경로 미리보기, 예상 거리/시간/호구비 계산
과속카메라 참고 표시공공데이터 기반 단속카메라 정보를 참고용으로 표시
주행 기록사용자가 과거 주행 내역을 확인할 수 있도록 저장
설정 유지사용자가 설정한 요금 체계 및 앱 설정 유지

5. 정보의 저장 및 보안

5.1 저장 위치

주행 기록, 최근 검색, 최근 경로, 앱 설정은 사용자의 기기 내에 저장됩니다.

  • 개발자 운영 서버에 주행 기록 저장 없음
  • 클라우드 동기화 없음
  • 광고/분석 목적의 데이터 전송 없음
  • 호구게이션 및 과속카메라 참고 표시 기능 사용 시 Apple MapKit 및 공공데이터포털 API 통신 가능

5.2 보안

  • iOS의 샌드박스 환경에서 안전하게 보호됩니다
  • 다른 앱에서 접근할 수 없습니다
  • 기기 분실 시 iOS의 기기 암호화로 보호됩니다

6. 정보의 삭제

6.1 주행 기록 삭제

  • 개별 삭제: 기록 > 기록 선택 > 삭제
  • 전체 삭제: 기록 > 전체 삭제

6.2 앱 설정 초기화

설정 > 앱 정보 > 면책 동의 초기화

6.3 모든 데이터 삭제

앱 삭제 시 모든 데이터가 기기에서 완전히 삭제됩니다.

권한용도

8. 제3자 서비스 및 제공

호구미터는 광고, 분석, 판매 목적으로 수집 정보를 제3자에게 제공하지 않습니다. 다만 앱 기능 제공을 위해 다음 외부 서비스와 통신할 수 있습니다.

  • Apple MapKit: 장소 검색, 경로 계산, 지도 표시, 역지오코딩
  • 공공데이터포털(data.go.kr): 단속카메라 공개 데이터 조회
  • 광고 네트워크 없음
  • 분석 서비스 없음

9. 아동의 개인정보

호구미터는 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 앱은 개인 식별 정보를 수집하지 않으므로 연령 확인 절차가 없습니다.

10. 개인정보 처리방침의 변경

본 개인정보 처리방침은 법령 변경 또는 앱 기능 변경에 따라 수정될 수 있습니다.

  • 변경 시 앱 업데이트 노트 또는 앱 내 공지를 통해 안내합니다
  • 중요한 변경 시 앱 실행 시 별도 동의를 요청할 수 있습니다
