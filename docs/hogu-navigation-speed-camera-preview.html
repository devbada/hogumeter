과속카메라 표시 방식

경로 진행 방향 기준 약 600m 안 카메라만 표시합니다. 화면에는 제한속도 원형 표지만 간단히 노출합니다.

제한속도 이하

제한속도 원형 표지만 표시합니다. 긴 문장은 보여주지 않습니다.

제한속도 초과

제한속도보다 3km/h 이상 빠르면 작은 빨간 원형 `초과` 표시를 깜빡입니다.

카메라 없거나 API NODATA

아무 경고도 표시하지 않습니다. `NODATA_ERROR`는 실패가 아니라 해당 지역 데이터 없음으로 처리합니다.
