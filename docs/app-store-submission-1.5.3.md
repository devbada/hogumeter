# App Store Connect 제출 내용 — HoguMeter 1.5.3

업로드된 build `1.5.3 (1)`이 App Store Connect에서 처리 완료되어 선택 가능해진 뒤
아래 내용을 사용한다. 이 문서는 심사 제출 자체를 승인하거나 실행하지 않는다.

## 이 버전에서 업그레이드된 사항

```text
자동 잠금 동작과 백그라운드 처리 방식을 개선해 장시간 주행 중 불필요한 전력 사용을 줄였습니다.
주행 종료 후 위치 추적 및 관련 처리가 더 안정적으로 정리되도록 개선했습니다.
```

## 앱 심사 메모

```text
호구미터는 친구와의 드라이브에서 사용하는 엔터테인먼트용 택시미터 시뮬레이션 앱입니다. 계정 생성, 로그인, 결제는 없습니다.

검토 경로:
1. 앱 실행 후 면책 안내에서 ‘위 내용을 이해했으며, 재미로만 사용할 것에 동의합니다.’ 체크박스를 선택하고 ‘🐴 호구 시작!’을 탭합니다.
2. 메인 화면의 ‘시작’을 탭합니다.
3. 주행 거리와 시간을 측정하려면 위치 권한을 허용합니다. 활성 주행을 백그라운드에서도 계속 측정하는 기능을 검토하려면 위치 권한을 ‘항상 허용’으로 설정해 주세요.
4. 정지 시 ‘정지’, 종료·초기화 시 ‘리셋’을 탭합니다. 1.5.3에서는 리셋하거나 앱이 비활성/백그라운드로 전환되면 iOS 자동 잠금이 허용됩니다.

알림 권한은 주행 중 장시간 움직임이 없을 때의 로컬 알림을 위한 선택 권한입니다. 거부해도 핵심 미터 기능은 사용할 수 있습니다. 사진 보관함 추가 권한은 영수증 이미지를 사진 앱에 저장할 때만 요청됩니다.
```

## 제출 전 계정 화면 확인

- [ ] build `1.5.3 (1)`이 처리 완료되어 해당 iOS 앱 버전에 연결 가능한가?
- [ ] App Privacy 라벨이 실제 동작 및 개인정보처리방침과 일치하는가? 위치 정보는 활성 미터의 거리·요금·경로/현재 위치 표시에만 사용하며, 주행 기록은 기기에 저장된다.
- [ ] 연령 등급, 가격 및 사용 가능 여부, 수출 규정이 최신 상태인가?
- [ ] 심사 연락처 정보가 유효한가?
- [ ] 6.5인치 및 iPad 스크린샷이 현재 1.5.3 UI를 반영하는가? 제거된 호구게이션을 암시하는 자산은 업로드하지 않는다.
- [ ] TestFlight 실기기에서 위치, 백그라운드 주행, 자동 잠금, 장시간 발열을 다시 확인했는가?

## 의도적으로 제외한 사항

- 호구게이션의 복구 또는 기능 언급
- 자동 심사 제출, 자동 출시, 사용자 동의 없는 계정 메타데이터 변경
